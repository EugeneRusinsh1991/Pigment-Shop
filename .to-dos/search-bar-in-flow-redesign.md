### Редизайн поведения SearchBar: Статический элемент страницы (In-Flow Layout)

#### 1. Описание задачи
Поисковая строка (`StoreSearchHeader`) переводится из режима динамически всплывающего зафиксированного заголовка (sticky floating header) в режим **обычного элемента страницы (in-flow element)**.
- Поисковая строка расположена вверху страницы над главным баннером (Hero Banner).
- Она ведет себя как стандартный блок документа: уезжает вверх вместе со всем контентом при скролле вниз и появляется при прокрутке страницы обратно наверх к началу.
- Отсутствуют принудительные скриптовые анимации ("вылетания" и "скрытия" по событиям скролла), панель не перекрывает контент во время прокрутки.

---

#### 2. Расположение ключевых файлов и компонентов
- **`src/features/shell/StoreSearchHeader.js`** — Компонент поисковой строки. Содержит переключатель `ENABLE_STICKY_SCROLL_HIDE`. При `false` рендерится как стандартный `View` (`position: 'relative'`).
- **`src/hooks/useHomeScrollHide.js`** — Хук отслеживания событий мыши и тача (`wheel`, `touchstart`, `touchmove`). При `disabled = true` автоматически отключает обработчики событий.
- **`app/(store)/_layout.js`** — Корневой макет магазина. Рендерит `<StoreSearchHeader />` над основным блоком контента `<View style={styles.mainContent}>` и баннером.
- **`src/theme/appStyles.js`** — Стили контейнера `stickySearchContainer` и внутреннего блока поиска `searchInner`.
- **`app/(store)/index.js`** — Главный роут магазина, вызывающий `CatalogView` с включенным баннером (`showHeroBanner={true}`).

---

#### 3. Контекст ранее выполненных работ и изменения поведения
- **Ранее (Аудит 05):** В хуке `useHomeScrollHide.js` были добавлены заградительные проверки (`scrollY <= 0` и `scrollY >= maxScrollY`) для устранения дергания дельты тача при эффекте "резинки" (iOS rubber-band bounce).
- **Текущие изменения (In-Flow Redesign):** В связи с переводом поисковой строки в естественный поток документа (in-flow layout), поисковый блок больше не зафиксирован поверх страницы (`position: sticky` временно отключен) и не использует хук анимации `useHomeScrollHide`. Все наработки по предотвращению заикания дельты сохранены в `useHomeScrollHide.js` для случая включения липкого режима.

---

#### 4. Механизм переключения режимов и отката (Rollback Feature)
Для быстрого возврата к старому динамическому поведению в `src/features/shell/StoreSearchHeader.js` внедрен флаг управления:

```javascript
// Флаг режима отображения поисковой строки:
// false = Статический элемент страницы над баннером (Новое поведение)
// true  = Динамическая липкая шапка с вылетанием при скролле (Старое поведение)
const ENABLE_STICKY_SCROLL_HIDE = false;
```

- **Новый режим (`ENABLE_STICKY_SCROLL_HIDE = false`):**
  Поисковая строка рендерится как простой блок `position: 'relative'`, хук скролла не навешивает глобальные обработчики событий.
- **Старый режим (`ENABLE_STICKY_SCROLL_HIDE = true`):**
  Код автоматического скрытия и анимации `Animated.View` полностью сохранен и активируется простой сменой флага на `true`.

---

### Инструкция по проверке и тестированию

1. **Откройте приложение:**Перейдите на `http://localhost:8081` в браузере.
2. **Проверка поведения:**
   - На Главной странице поисковая строка находится над баннером.
   - Прокрутите страницу вниз — строка поиска естественным образом уходит за верхний край вместе с контентом.
   - Прокрутите страницу наверх — строка поиска появляется при возврате к вершине страницы.
3. **Проверка отката:**
   - В `StoreSearchHeader.js` измените `ENABLE_STICKY_SCROLL_HIDE` на `true`.
   - Сохраните файл — поисковая строка снова станет плавающей липкой шапкой с анимацией скрытия.
