# Задача по оптимизации dispatchContinuousEvent Lag

## Описание проблемы
Зафиксирован лаг **122мс** в `dispatchContinuousEvent` во время непрерывного взаимодействия (прокрутка, перетаскивание).

## Шаги для локализации и исправления
1. Локализовать тяжелые списки (`ScrollView`, `FlatList`) или слайдеры.
2. Внедрить троттлинг (`throttle`) для обработчиков скролла и перемещения.
3. Оптимизировать частоту обновления состояния при прокрутке.
