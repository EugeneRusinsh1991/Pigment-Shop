# Задачи по оптимизации React Scheduler Lag (performWorkUntilDeadline)

## Описание проблемы
При взаимодействии с интерфейсом Playwright зафиксировал задержку **351мс** (порог 100мс), вызванную долгим выполнением задач в React Scheduler (`performWorkUntilDeadline`). Это указывает на тяжелый рендеринг компонентов или блокирующие вызовы внутри хуков.

## Шаги для локализации и исправления
1. **Профайлинг React**: Запустить React Profiler и записать сценарий кликов по каталогу и фильтрам для выявления тяжелых компонентов.
2. **Мемоизация тяжелых вычислений**: Проверить хуки `useEffect`, `useMemo` и коллбэки в компонентах каталога и фильтров.
3. **Оптимизация списков**: Убедиться, что списки товаров используют виртуализацию или `React.memo` для элементов.
