Project purpose
- Mobile and web storefront application for a retail/shop experience, implemented as an Expo-based React Native app.

Technology stack
- Expo application runtime
- React and React Native
- Firebase SDK for backend services
- Metro bundler/runtime via Expo

Programming languages
- JavaScript
- TypeScript (development tooling)

Frameworks
- Expo
- React Native
- React Native Web

Major dependencies
- expo
- react
- react-native
- react-native-web
- firebase
- expo-status-bar
- @expo/metro-runtime
- TypeScript and @types/react for development

Overall project structure
- `src/`: main application source code with components, context, services, hooks, theme, and utilities
- `src/components/`: UI screens and reusable components for catalog, cart, orders, profile, navigation, admin, and layout
- `auditor/`: code analysis and reporting tools
- `backuper/`: backup and restore scripts
- `scripts/`: utility scripts for media manifest generation and database regeneration
- `media/`: media assets and manifest
- `app.json` / `app.config.js`: Expo app configuration
- `index.js`: entry point for the Expo app
- `package.json`: dependency and script configuration
