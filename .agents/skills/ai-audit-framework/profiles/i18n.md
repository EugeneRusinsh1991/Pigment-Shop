# Internationalization (i18n) Audit Profile

## Focus Areas
1. **Localization & Text Extraction**:
   - Hardcoded user-visible strings in JSX/components instead of translation keys (`t('key')`).
   - Hardcoded date, time, or currency formatting instead of Intl API.

2. **RTL & Dynamic Content**:
   - Direction-specific CSS properties (`left`, `margin-right`) instead of logical properties (`inline-start`, `margin-inline-end`).
