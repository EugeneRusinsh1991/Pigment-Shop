# Project Commands & Scripts Reference

Документ содержит полный реестр CLI-команд проекта с разделением по категориям. Предназначен для пополнения новыми командами.

---

## 💾 1. Database & Seed (`.database`)

Команды генерации и управления тестовыми данными в Firebase.

* **`npm run regenerate-database`**  
  *Описание*: Полная регенерация базы данных Firebase (стандартный режим). Удаляет текущие категории, товары и заказы, затем создает объемный датасет (2–4 категории на каждом уровне, десятки товаров, 10–20 заказов на пользователя).  
  *Назначение*: Полноценное ручное тестирование UI, нагрузочные проверки.

* **`npm run regenerate-database-low`** (или `node scripts/regenerateDatabase.js --low`)  
  *Описание*: Легковесная регенерация базы данных (Lightweight mode). Удаляет текущие данные и создает минимальный реалистичный датасет (по 2 категории на уровень, по 1 товару на подгруппу, 1–2 заказа на пользователя), полностью сохраняя 3-уровневую структуру каталога.  
  *Назначение*: Ускорение работы автоматизированного тестирования (Browser Automation) и сокращение глубины обхода DOM.

## 🧰 2. Developer Tools (`.tools`)

Автономные утилиты для разработки, обслуживания и контроля качества codebase.

### 📦 2.1. `.backuper` — Backup & Restore
* **`npm run backup`**  
  *Описание*: Создает автоматический бэкап текущего состояния проекта с отметкой времени в родительской директории (игнорирует `node_modules`, `dist`, `.git` и т.д.). Записывает JSON-дифф изменений относительно предыдущего бэкапа.
* **`npm run restore`**  
  *Описание*: Запускает интерактивное меню CLI для выбора и восстановления из 20 последних бэкапов. Перед восстановлением автоматически создает контрольный снимок безопасности (`_backup_before_restore_*`).
* **`npm run restore <backup_path>`**  
  *Описание*: Прямое восстановление проекта из указанной папки бэкапа.

### 🔍 2.2. `.auditor` — Codebase Health & Static Analysis
* **`npm run audit`**  
  *Описание*: Запускает статический анализ проекта и генерирует отчет в `.auditor-reports/project/Codebase-Audit-Report.md` (неиспользуемые зависимости, неиспользуемый код, дублирование).

### 🧹 2.3. `.cleaner` — Artifact & Cache Cleanup
* **`npm run clean`**  
  *Описание*: Безопасно очищает кэш-директории и артефакты сборки (`.expo`, `dist`, `web-build`, `test-results`, `coverage`, `.cache`, временные бэкапы).

### 🏥 2.4. `.health` — Environment Integrity
* **`npm run health`**  
  *Описание*: Проверяет окружение Node.js, синтаксис `package.json`, синхронизацию ключей `.env` vs `.env.example`, а также сканирует проект на наличие битых относительных импортов.

### 📦 2.5. `.packer` — Codebase Archiver
* **`npm run pack`**  
  *Описание*: Упаковывает чистый исходный код проекта (без `node_modules`, `.git` и артефактов) в zip-архив с отметкой времени в родительской папке.

## 🚀 3. Application Development (`app`)

Команды запуска и сборки приложения Expo/React Native.

* **`npm run dev`** / **`npm run start`** — Запуск Expo dev-сервера.
* **`npm run web`** — Запуск веб-версии приложения.
* **`npm run android`** — Запуск приложения на эмуляторе/устройстве Android.
* **`npm run ios`** — Запуск приложения на эмуляторе iOS.
* **`npm run generate-media`** — Генерация манифеста медиа-файлов (`scripts/generateMediaManifest.js`).
* **`npm run type-check`** — Проверка типов TypeScript (`tsc --noEmit`).
