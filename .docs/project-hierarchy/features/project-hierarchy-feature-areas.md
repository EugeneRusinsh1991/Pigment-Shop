# Feature Modules Layer

## Responsibility
Encapsulated domain feature modules located under `src/features/`.

## When to use
Open when editing business features, complex screen workflows, or feature-specific logic.

## Key Feature Directories (`src/features/`)

- [admin/](file:///d:/Magazine/_PigmentShop/src/features/admin/) — Administrative dashboard feature components and logic.
- [auth/](file:///d:/Magazine/_PigmentShop/src/features/auth/) — Sign-in, sign-up forms, and auth logic.
- [cart/](file:///d:/Magazine/_PigmentShop/src/features/cart/) — Cart view, drawer, and checkout logic.
- [catalog/](file:///d:/Magazine/_PigmentShop/src/features/catalog/) — Catalog filters, search grid, pagination, category cards.
- [contact/](file:///d:/Magazine/_PigmentShop/src/features/contact/) — Customer support and feedback form feature.
- [favorites/](file:///d:/Magazine/_PigmentShop/src/features/favorites/) — User favorite products listing feature.
- [home/](file:///d:/Magazine/_PigmentShop/src/features/home/) — Hero banner, featured products, homepage sections.
- [orders/](file:///d:/Magazine/_PigmentShop/src/features/orders/) — Customer order list and order details view.
- [product/](file:///d:/Magazine/_PigmentShop/src/features/product/) — Product detail page, reviews, image gallery.
- [profile/](file:///d:/Magazine/_PigmentShop/src/features/profile/) — User profile settings and form editing.
- [shell/](file:///d:/Magazine/_PigmentShop/src/features/shell/) — Root application layout container & headers.
