# App Shell - Root Entry Points

## Purpose
Provides Expo Router entry points, root bootstrap wrappers, and the shared application shell composition.

## Responsibility
Encapsulates the router layout under app/, route screens such as home, products, and profile, and the main shell composition in src/App.js.

## When to use
Open when adding or changing routes, updating the app layout, or modifying the shared shell composition.
