# Stage 2 — Batch Audit Report: [explorer-modules-plugins]

## Metadata
- **Batch Step ID**: 2.4
- **Profile**: Architecture
- **Scope**: `.tools/browser-automation/explorer/{di,events,graph,modules,observability,policy,diagnostics,driver,utils}/*`, `.tools/browser-automation/plugins/*`

## Strengths
- **Type-Safe Event Bus System**: `ExplorerEventEmitter` provides generic strongly-typed event registration (`ExplorerEventMap`) with handler-level try-catch isolation.
- **Pluggable Architecture**: `SmokePlugin` cleanly hooks into the core event emitter to perform DOM health checks and console error analysis without altering `UIExplorer` core logic.
- **DI Composition Factory**: `createDefaultContainer()` provides a single unified factory method to assemble the full suite of automation services.

## Findings

### [FINDING-013]: Rigid Concrete Instantiation in DI Container Factory
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `.tools/browser-automation/explorer/di/DIContainer.ts#L41-L95`
- **Evidence**:
  ```ts
  // DIContainer.ts
  const tracker = new NavigationTracker();
  const scanner = new ElementScanner();
  const interactor = new ElementInteractor();
  ```
- **Observation**: `createDefaultContainer()` hardcodes `new Class()` instantiations directly rather than accepting configurable provider overrides.
- **Impact**: Reduces testability; prevents mock injection for individual infrastructure components during isolated unit testing.

### [FINDING-014]: Node.js Event Loop Timer Leaks in ExecutionWatchdog
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `.tools/browser-automation/explorer/diagnostics/ExecutionWatchdog.ts#L68-L99`
- **Evidence**:
  ```ts
  // ExecutionWatchdog.ts
  private startTimer(): void {
    this.stopTimer();
    this.timer = setInterval(() => this.checkProgress(), 1000);
  }
  ```
- **Observation**: The watchdog uses un-unref'd `setInterval()` loops. If an unhandled exception bypasses `endInteraction()`, the timer remains active on the Node event loop.
- **Impact**: Prevents process termination upon completion or failure; requires manual process kills in CI environments.

### [FINDING-015]: Duplicate Report Formatting Across Plugin Boundaries
- **Severity**: Low
- **Confidence**: High
- **Affected Scope**: `.tools/browser-automation/plugins/smoke/SmokeReportPrinter.ts#L1-L100`, `.tools/browser-automation/explorer/observability/reporters/MarkdownReporter.ts#L1-L80`
- **Evidence**: `SmokeReportPrinter` independently formats terminal outputs and markdown tables, duplicating formatting utilities defined in `observability/reporters/`.
- **Impact**: Inconsistent console visual aesthetics and fragmented reporting templates.
