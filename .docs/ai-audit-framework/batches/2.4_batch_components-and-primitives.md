# Stage 2 — Batch Audit Report: [components-and-primitives]

## Metadata
- **Batch Step ID**: 2.4
- **Profile**: Architecture Audit Profile (`architectural`)
- **Scope**: `src/components/`, `src/theme/`

## Strengths
- **Centralized Design Token Foundation**: `src/theme/tokens.js` defines an extensive design token architecture containing palette colors, spacing, radii, breakpoints, and shadows.
- **Decomposed Complex Views**: Complex views such as `CatalogPage.js` and `ProductPage.js` break down layouts into sub-components (`CatalogFilterSidebar`, `CatalogSortBar`, `ProductGrid`).
- **Reusable Layout & Animation Utilities**: Generic primitives like `PageTransition.js`, `ScrollFadeUp.js`, and `SharedLayoutWrapper.js` decouple screen animation and wrapper logic from domain screens.

## Findings

### [FINDING-001]: Pervasive Bypass of Theme Tokens for Hardcoded Color Literals
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `src/components/NavigationCard.js#L14`, `src/components/Footer.js#L37-L80`, `src/components/PageNavigation.js#L83-L122`, `src/components/FeaturedSections.js#L99-L156`, `src/components/NewArrivalsFooter.js#L38`, `src/components/OrderCard.helpers.js#L100`
- **Evidence**:
  ```javascript
  // Footer.js
  backgroundColor: '#0D0D0D',
  borderTopColor: '#242424',
  color: '#E31B23',
  ```
- **Observation**: UI components contain over 100 occurrences of hardcoded hex color literals (`'#0D0D0D'`, `'#FAF8F6'`, `'#94a3b8'`, `'#64748b'`, `'#38bdf8'`, `'#7c3aed'`) rather than importing theme tokens from `src/theme/tokens.js`.
- **Impact**: Undermines global theme tokens, creates visual inconsistency between dark/light modes, and complicates project-wide color rebranding.

### [FINDING-002]: Fragmented Touchable & Button Primitives
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `src/components/AnimatedButton.js`, `src/components/Button.js`, `src/components/ChipButton.js`, `src/components/IconButton.js`
- **Evidence**:
  - `src/components/Button.js`
  - `src/components/AnimatedButton.js`
  - `src/components/ChipButton.js`
  - `src/components/IconButton.js`
- **Observation**: The component layer maintains 4 parallel, un-unified button primitive files, each implementing its own press animations, prop signatures, and touch target constraints.
- **Impact**: Duplicate styling overhead, inconsistent press feedback across screens, and lack of a single source of truth for clickable interactive elements.
