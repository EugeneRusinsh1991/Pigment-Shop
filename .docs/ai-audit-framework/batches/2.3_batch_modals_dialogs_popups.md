## Findings

### [FINDING-009]: Native `window.alert()` & `window.confirm()` Browser Sprawl
- **Severity**: High
- **Confidence**: High
- **Affected Scope**: `src/hooks/useCrudWorkflow.js#L18-L22`, `src/hooks/useDeleteConfirmation.js#L6-L25`, `src/components/CartView/cartCheckoutLogic.js#L4-L8`
- **Evidence**:
  ```js
  // useCrudWorkflow.js
  if (isWebAlertAvailable) {
    window.alert(text);
  }
  // useDeleteConfirmation.js
  if (Platform.OS === 'web') {
    const confirmed = window.confirm(title);
  }
  ```
- **Observation**: Destructive action confirmations (deleting products/categories) and order notifications fall back to native web browser `window.alert()` and `window.confirm()`.
- **Impact**: Un-themed native browser dialogs interrupt web user experience, lock thread execution, and bypass design system theme tokens.

### [FINDING-010]: Un-unified Scrim & Backdrop Overlay Styles
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `src/components/SideDrawer.js#L15-L25`, `src/components/Admin/SharedFormComponents.js#L2`
- **Evidence**:
  ```js
  // SideDrawer backdrop:
  backgroundColor: 'rgba(0, 0, 0, 0.5)'
  // SharedFormComponents backdrop:
  backgroundColor: 'rgba(0, 0, 0, 0.65)'
  ```
- **Observation**: Backdrop color opacity (`rgba(0,0,0,0.5)` vs `0.65`), blur effects, and backdrop dismiss click handlers are defined ad-hoc per modal component.
- **Impact**: Inconsistent visual depth and contrast when opening navigation drawers vs admin edit form modals.

### [FINDING-011]: Non-Standardized Notification & Feedback Toast Controls
- **Severity**: Medium
- **Confidence**: High
- **Affected Scope**: `src/features/profile/ProfilePage.js#L52`, `src/components/CartView/cartCheckoutLogic.js#L44-L49`
- **Evidence**:
  ```js
  // ProfilePage custom alert component:
  function ProfileSaveAlert({ saveMessage, isDark }) { ... }
  ```
- **Observation**: The app lacks a global Toast / Notification Provider. Success and error notifications are implemented via inline custom banners (`ProfileSaveAlert`) or native alerts.
- **Impact**: Inconsistent notification placement, lack of auto-dismiss timing controls, and fragmented feedback UX.

### [FINDING-012]: Hardcoded Overlay `zIndex` Sprawl
- **Severity**: Low
- **Confidence**: High
- **Affected Scope**: `src/features/shell/AppHeader/UserDropdown.js`, `src/components/HeaderDropdown.js`
- **Evidence**:
  ```js
  // Dropdowns and overlays use arbitrary zIndex values (100, 1000, 9999)
  ```
- **Observation**: Overlay z-indexes are assigned manually without referencing design tokens (`layout.zIndices`).
- **Impact**: Risk of z-index collision where dropdowns hide behind modal backdrops or sticky headers.
