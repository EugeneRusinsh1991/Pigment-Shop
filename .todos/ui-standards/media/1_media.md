# Стандарт UI-модуля: Media

## 1. Что это за элемент и зачем он нужен
`Media` — набор компонентов для рендеринга медиаконтента (`GifRenderer`, `VideoRenderer`, `MediaRenderer`).

## 2. Где находится в коде
- **Путь к исходникам:** [`src/components/Media/`](file:///d:/Magazine/_PigmentShop/src/components/Media/)
- **Текущие файлы:**
  - `MediaRenderer.js`, `GifRenderer.js`, `VideoRenderer.js`
  - `index.js`

## 3. Пример использования
Проигрывание промо-видео покраски на главной странице, анимации гифок в блоге и галерее товаров.

## 4. Что требуется для приведения к стандарту `_reference-module-spec.md`
- [ ] Выделить общий файл стилей `MediaStyles.js`.
- [ ] Создать `useMediaTheme.js` для темного/светлого состояния плеера.
- [ ] Оформить спецификацию модуля.
